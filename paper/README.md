# paper - generated outputs for the write-up

- `tables/` - Markdown and LaTeX tables, produced by `experiments/make_tables.py`
- `figures/` - PNG and PDF figures, produced by `experiments/make_figures.py`
- `notes/` - short findings files, one per experiment, written in plain language

Nothing in here is typed by hand. Every number must come from a run under
`experiments/results/` (hard rule 2 in `PROJECT_RULES.md`).
